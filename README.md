# Alfredo M. Semilla Jr. - Three Page Website

Pages:
- `index.html` — Boba Bliss landing page (HTML + CSS)
- `personal-space.html` — Personal Space page
- `bootstrap-space.html` — Bootstrap Personal Space page

All three pages are connected through the navigation menu.

## GitHub Pages
1. Create a GitHub repository.
2. Upload everything in this folder (not the ZIP itself).
3. Go to Settings -> Pages.
4. Under Build and deployment, choose `Deploy from a branch`.
5. Select `main` and `/ (root)`, then Save.
6. Open the generated GitHub Pages URL.
